一款简洁、二次元风、响应式且对开发者友好的 WordPress 博客主题。写代码，也写猫与生活。

== Description ==

NanoCat 是一套为个人博客准备的主题：有午夜的城、晨雾的城、窗边的猫和蔚蓝 / 钢蓝的冷峻配色，也有程序员喜欢的等宽字体、代码块和清楚的层级。没有夸张的动效，没有外部字体和 CDN，打开就能用。

主要特性：

* 响应式布局，桌面、平板和手机都有单独调整。
* 浅色 / 深色模式，支持跟随系统，也会记住访客的选择。
* 首页 Hero：全屏原创明暗双版插画，随浅色 / 深色主题自动切换，也可在定制器中分别替换。
* 首页三栏：左侧资料与分类、中间横版文章流、右侧热门与标签；两侧均可切换为小工具。
* 侧边栏：个人资料、热门文章、标签云、引用卡片；也可以切换到小工具。
* 文章页：阅读进度、自动目录（h2/h3）、代码一键复制、分享 / 复制链接、作者卡片、上下篇、相关文章。
* 评论：自定义评论样式、中文表单、嵌套回复。
* 归档、搜索、404 页面都有完整设计。
* 专栏：文章可勾选多个专栏，自动生成 `/topics/` 首页、按阅读顺序排列的专栏归档与首页专栏横条。
* Wiki：使用层级页面创建项目与文档，自动生成 `/wiki/` 项目首页、项目目录树、上一篇 / 下一篇。
* 友链与 RSS：使用 WordPress 链接管理，填写 RSS 后聚合好友最近文章，带健康状态、后台一键刷新与定时缓存。
* 内容后台：外观 → NanoCat 内容，集中管理专栏、Wiki 和友链缓存；首次启用自动创建专栏页与友链页。
* 可访问性：跳转链接、键盘焦点、ARIA 属性、减少动效支持。
* 编辑器样式与前端保持一致，支持宽对齐和全宽区块。
* 无构建步骤，无外部依赖，所有插画均为主题内置 SVG。

== Installation ==

1. 在 WordPress 后台进入“外观 → 主题 → 安装主题”，上传 `nanocat.zip` 并启用。
2. 进入“外观 → 自定义 → NanoCat 主题选项”，设置首页文案、个人介绍、社交链接和页脚文字。
3. 进入“外观 → 菜单”，创建菜单并分配到“主导航”和“页脚导航”。
4. 可选：在“外观 → 小工具”中给“侧边栏”添加小工具；不添加时会显示主题自带的个人卡片、热门文章、专栏、Wiki、标签云和引用。
5. 建议为文章设置特色图片。没有特色图片时，主题会按文章 ID 自动使用三张内置插画之一。
6. 首次启用后，主题会自动创建“专栏”和“友链”页面；在“文章 → 专栏”中建立系列，在“Wiki”中建立项目与子页面。
7. 在“链接 → 添加链接”中填写好友站点和 RSS 地址，然后到“外观 → NanoCat 内容”点击“立即刷新”。

== Frequently Asked Questions ==

= 首页的终端文字和按钮在哪里改？ =

外观 → 自定义 → NanoCat 主题选项 → 首页 Hero。标题支持 `<br>`、`<span>`、`<em>`、`<strong>` 和 `<b>`。

= 首页头图会随浅色 / 深色主题切换吗？ =

会。浅色模式使用 `assets/images/hero-light.svg`，深色模式使用 `assets/images/hero-night.svg`；在“外观 → 自定义 → NanoCat 主题选项 → 首页 Hero”中可以分别上传“浅色模式头图”和“深色模式头图”。

= 为什么侧边栏没有显示我添加的小工具？ =

首页有“首页左栏”和“首页右栏”两个小工具区域，文章归档页使用“侧边栏”。不添加小工具时，主题会显示内置的个人资料、分类、专栏、热门文章、Wiki 与标签内容；添加任意小工具后自动切换。

= 没有设置特色图片会怎样？ =

文章卡片和文章页会使用主题内置的三张 SVG 插画，根据文章 ID 自动选择，不会出现空白封面。

= 代码复制按钮需要额外插件吗？ =

不需要。主题会自动为文章正文中的代码块添加复制按钮。剪贴板 API 不可用时会自动回退到兼容方案。

= 主题支持中文吗？ =

支持。主题针对中文排版做了字号、行高和标点处理，界面文案也是中文。Text Domain 为 `nanocat`。

= 专栏和 Wiki 需要安装插件吗？ =

不需要。专栏使用 WordPress 原生分类法，Wiki 使用层级自定义文章类型，都可在后台直接编辑。

= 友链页面为什么暂时没有文章？ =

友链的 RSS 与健康状态使用缓存，首次启用或新增链接后需要到“外观 → NanoCat 内容”点击“立即刷新”，之后每 12 小时自动更新。

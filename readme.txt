一款简洁、二次元风、响应式且对开发者友好的 WordPress 博客主题。写代码，也写猫与生活。

== Description ==

NanoCat 是一套为个人博客准备的主题：有午夜的城、蔚蓝的晨光、窗边的猫和蔚蓝 / 青绿的清爽配色，也有程序员喜欢的等宽字体、代码块和清楚的层级。没有夸张的动效，没有外部字体和 CDN，打开就能用。

主要特性：

* 响应式布局，桌面、平板和手机都有单独调整。
* 浅色 / 深色模式，支持跟随系统，也会记住访客的选择。
* 首页 AI 优先：第一屏只有标题、大号提问框和具体问题建议，回答直接在页面内流式展开；博客文章退到下方，以安静的编号索引呈现，不再使用大图 Hero、资料卡或三栏卡片。
* AI 原生体验：页头“问 AI”或 `⌘/Ctrl K` 打开全局对话；回答以 SSE 流式呈现并附带站内来源，支持会话历史与随时停止。
* 文章 AI 伴读：自动生成摘要，可一键“三句话总结 / 列出要点 / 讲人话 / 考考我”，选中正文可直接追问。
* AI 工作台：独立的 `/ai/` 页面，包含大对话区、知识地图、最近提问和最新文章；首次启用自动创建。
* AI 接入：复用站点的 `/api/ai` 服务，前端不新增密钥；主题会移除旧的飞鱼浮窗，统一使用 NanoCat 界面。
* 首页索引：无图片的编号文章流，显示分类、日期、标题、摘要和阅读时间；文章页仍保留完整的视觉叙事。
* 侧边栏：个人资料、热门文章、标签云、引用卡片；也可以切换到小工具。
* 文章页：阅读进度、自动目录（h2/h3）、代码一键复制、分享 / 复制链接、作者卡片、上下篇、相关文章。
* 评论：自定义评论样式、中文表单、嵌套回复。
* 归档、搜索、404 页面都有完整设计。
* 专栏：文章可勾选多个专栏，自动生成 `/topics/` 首页、按阅读顺序排列的专栏归档与首页专栏横条。
* Wiki：使用层级页面创建项目与文档，自动生成 `/wiki/` 项目首页、项目目录树、上一篇 / 下一篇。
* 友链与 RSS：使用 WordPress 链接管理，填写 RSS 后聚合好友最近文章，带健康状态、后台一键刷新与定时缓存。
* 内容后台：外观 → NanoCat 内容，集中管理专栏、Wiki 和友链缓存；首次启用自动创建专栏页与友链页。
* 可访问性：跳转链接、键盘焦点、ARIA 属性、减少动效支持。
* 编辑器样式与前端保持一致，支持宽对齐和全宽区块。
* 无构建步骤，无外部依赖，所有插画均为主题内置 SVG。

== Installation ==

1. 在 WordPress 后台进入“外观 → 主题 → 安装主题”，上传 `nanocat.zip` 并启用。
2. 进入“外观 → 自定义 → NanoCat 主题选项”，设置首页文案、个人介绍、社交链接和页脚文字。
3. 进入“外观 → 菜单”，创建菜单并分配到“主导航”和“页脚导航”。
4. 可选：在“外观 → 小工具”中给“侧边栏”添加小工具；不添加时会显示主题自带的个人卡片、热门文章、专栏、Wiki、标签云和引用。
5. 建议为文章设置特色图片。没有特色图片时，主题会按文章 ID 自动使用三张内置插画之一。
6. 首次启用后，主题会自动创建“归档”“专栏”“友链”和“AI 工作台”页面，并套用各自模板；在“文章 → 专栏”中建立系列，在“Wiki”中建立项目与子页面。
7. 在“链接 → 添加链接”中填写好友站点和 RSS 地址，然后到“外观 → NanoCat 内容”点击“立即刷新”。
8. AI 功能依赖站点已有的 `/api/ai/ask` 与 `/api/ai/summary` 接口；若站点没有兼容后端，主题其余部分仍可正常使用，AI 面板会显示错误提示。

== Frequently Asked Questions ==

= 首页的标题、介绍和按钮在哪里改？ =

外观 → 自定义 → NanoCat 主题选项 → 首页 AI。标题支持 `<br>`、`<span>`、`<em>`、`<strong>` 和 `<b>`；首页的大输入框本身就是 AI 提问入口，不需要额外配置。

= 首页为什么没有头图？ =

3.1 首页改成 AI 优先的极简结构：第一屏只负责提问，文章以编号索引放在下方，索引两侧恢复左栏与右栏。头图不再占用首屏；归档、搜索和文章页仍保留完整布局。

= 在哪里添加小工具？ =

首页、归档、搜索和文章页都使用“侧边栏”；首页还提供“首页左栏 / 首页右栏”两个独立小工具区域。

= 没有设置特色图片会怎样？ =

文章卡片和文章页会使用主题内置的三张 SVG 插画，根据文章 ID 自动选择，不会出现空白封面。

= 代码复制按钮需要额外插件吗？ =

不需要。主题会自动为文章正文中的代码块添加复制按钮。剪贴板 API 不可用时会自动回退到兼容方案。

= 主题支持中文吗？ =

支持。主题针对中文排版做了字号、行高和标点处理，界面文案也是中文。Text Domain 为 `nanocat`。

= 专栏和 Wiki 需要安装插件吗？ =

不需要。专栏使用 WordPress 原生分类法，Wiki 使用层级自定义文章类型，都可在后台直接编辑。

= 友链页面为什么暂时没有文章？ =

友链的 RSS 与健康状态使用缓存，首次启用或新增链接后需要到“外观 → NanoCat 内容”点击“立即刷新”，之后每 12 小时自动更新。

= AI 功能需要插件或 API Key 吗？ =

主题本身不保存 API Key，只调用站点已有的 `/api/ai` 服务。兼容的后端需要提供 `POST /api/ai/ask`（SSE 返回 sources 与 delta）和 `GET /api/ai/summary?post=ID`。旧的飞鱼 AI 前端会被主题自动移除，避免两套浮窗重复出现。

= 为什么 AI 说“没有检索到相关内容”？ =

站内检索依赖具体关键词。试试“窗口服务是怎么实现的”“推荐一条从零写内核的路线”，比“介绍一下这个博客”更容易命中文章。
